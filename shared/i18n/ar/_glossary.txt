Arabic (ar) glossary for Overlap — Modern Standard Arabic
Style: buttons use the verbal noun (masdar): «إنشاء استطلاع», «نسخ», «حفظ التغييرات».
Hints/errors address the user with the masculine generic imperative: «اختر», «أدخل», «أضف».
Punctuation: ، ؛ ؟ and quotes «…». Keep Overlap, Micropeptide, GitHub etc. in Latin script.

many  → {count} + singular accusative, e.g. {count} ردًّا
